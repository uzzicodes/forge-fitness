Set up offline gym access

For offline access, use the secure version below. A one-time certificate setup is needed because the app is hosted on your own computer.

  1. On your computer, run Setup-iPhone.cmd, then restart Start-Forge.cmd.
  2. Download your computer’s FORGE certificate. In iPhone Settings, open Profile Downloaded (or General → VPN & Device Management), inspect the FORGE profile, and install it.
  3. Open Settings → General → About → Certificate Trust Settings and enable trust for FORGE Local Development CA. This allows Safari to verify your own computer. Apple’s certificate instructions.
  4. Open secure FORGE

    Use the same computer address each time. Do not bypass a Safari certificate warning; check the certificate setup instead.

  5. In Safari, use Share → Add to Home Screen, enable Open as Web App if shown, and tap Add. Open the new icon while still connected to Wi-Fi.
  6. Wait for the Offline ready message. Test by turning off Wi-Fi/cellular and reopening the app. Workouts, manual meal logs and progress can then use the saved app. AI food estimates still need a connection to your computer and the internet.

Browser storage can be cleared or evicted. Use Settings → Export backup regularly. HTTP and HTTPS have separate local data; restore a backup if you already started in the HTTP app.

Food name or photo estimates

Add your OpenAI API key to server/.env on the computer and restart the server. Then enter the pairing token from its console into FORGE Settings. Leave the server address blank on iPhone to use the same origin.

Try “banana shake” and add your ingredients or glass size. Review the assumed recipe, calories and protein before saving. API usage may be billed by OpenAI.
